# CAD original — Grupo 17

Autores del proyecto:

- Luis Fernando Vélez Burgos
- Samuel Gabriel Salazar Espinoza

`Samuel_WS2_description_original.zip` es una copia exacta del archivo
`Samuel_WS2_description (2).zip` proporcionado para el proyecto.
Contiene la exportación de Fusion 360 para ROS 2: mallas STL, URDF/Xacro,
archivos de lanzamiento y configuración.

Los archivos originales se conservan dentro del ZIP. La versión adaptada para
simular y dibujar el número 7 está en `src/Samuel_WS2_description/`.

No se recibió un archivo editable de Fusion 360 (`.f3d` / `.f3z`) ni un STEP.
Las imágenes de `imagenes/` se obtienen de la geometría STL exportada.
